=== INSTALLATION ===

1. Download BepInEx 5.4.23.5 (win_x64):
   https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x64_5.4.23.5.zip

2. Open the game root directory:
 - Open Steam
 - Right-click "Casualties: Unknown"
 - Click: Manage > Browse local files

3. Extract BepInEx_win_x64_5.4.23.5.zip directly into the game root directory.

4. Extract CasualtiesTogether-v*.zip directly into the game root directory.
   (The zip already starts with BepInEx/plugins/Together/ — merge it into the game root.)
   * Quick update note: If you already installed the full zip before, you can also update by replacing BepInEx/plugins/Together/CasualtiesMP.dll with the standalone CasualtiesMP.dll from Releases.

Your game root directory should look like this:
  Casualties Unknown/
    - CasualtiesUnknown.exe
    - UnityPlayer.dll
    - UnityCrashHandler64.exe
    - CasualtiesUnknown_Data/
    - MonoBleedingEdge/
    - doorstop_config.ini              <- from BepInEx zip
    - winhttp.dll                      <- from BepInEx zip
    - BepInEx/
      - core/                          <- from BepInEx zip
      - plugins/
        - Together/                    <- from CasualtiesTogether-v*.zip
          - CasualtiesMP.dll
          - K4os.Compression.LZ4.dll
          - LiteEntitySystem.dll
          - LiteNetLib.dll
          - OpusSharp.Core.dll
          - opus.dll
          - RefMagic.dll
          - System.Runtime.CompilerServices.Unsafe.dll

5. Launch the game through Steam.
   (Linux / Proton users: set Steam Launch Options to WINEDLLOVERRIDES="winhttp=n,b" %command%)

6. Multiplayer buttons will appear at the bottom of the main menu.


=== CROSS-BUILD LOBBY COMPATIBILITY (VERIFY GAME HASH) ===

"Verify Game Hash" (enabled by default in host server settings) compares binary hashes of Assembly-CSharp.dll and CasualtiesMP.dll.
If players in the same lobby mix upstream v5.5.4 builds, this patched build, +debug builds, or nightly builds, the host should UNCHECK "Verify Game Hash" in the server settings panel so everyone with matching protocol version (1.0.2_MPv5.5.4) can join smoothly.
